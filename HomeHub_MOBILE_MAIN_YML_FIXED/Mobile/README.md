# HomeHub Mobile v1

Android telefon/tablet kliens HomeHubhoz.

- Offline-first UI
- Telefonon alsó navigáció
- Tableten oldalsáv
- Születési dátum az onboardingban
- Helyi HomeHub AI alap
- Android 8+ (API 26)
- GitHub Actions debug APK build

Megjegyzés: ez a kliens jelenleg saját helyi adatállapotot használ. A valódi PC ↔ telefon ↔ tablet családi szinkronhoz később közös helyi hálózati backend/sync réteg kell.
